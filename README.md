Predicting violent crime rates using socioeconomic and demographic factor by Anh Nguyen

For my project, I plan to reuse my 7040 Big Data Visualization final project. For this project, I explored the relationship between violent crime rates, poverty,and community age composition using the Communities and Crime dataset from the UCI Machine Learning Repository. For data preprocessing I will first clean my data by handling NAs, feature selection, and prepare data for model training. I will then split the data into 70/30 into training/testing sets. I will use Kubernetes on Nautilus. Since the dataset is relatively small, I will use CPU resources and 5G of memory. 

The main problem I’m addressing is seeing whether socioeconomic factors and community age can help predict violent crime rates across communities. This matters because it adds context to public safety research. Some specific goals may include looking at community characteristics and seeing which are most strongly associated with violent crime, then using it to train the model. For this project, I think I will probably use something similar to what I did in data viz, where I will use linear regression as the baseline model, then random forest, to see which potentially more complex relationships exist between predictors and the violent crime rates. For performance, I will use R^2, root mean square error or RMSE, and mean absolute error or MAE to see which has the highest feature importance to see the strongest predictors. 

For this project, I expect to be able to gain a better understanding on how socioeconomic and demographic factors relate to violent crime. I think one challenge that I might encounter is possibly random forest importance showing that no factors are strong predictors of violent crime, which could make it hard to achieve high model performance and possibly difficulties in data processing and model training on Kubernetes.
